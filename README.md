# meshtastic-bitchat-bridge

Bridges Meshtastic's LoRa mesh network with Bitchat's BLE mesh, so Bitchat
messages can hop onto LoRa for long-range relay between Bitchat clusters.

## Status

Early design/research phase. No hardware yet — building against a Raspberry
Pi target first (USB-serial Meshtastic radio + BLE adapter).
